# Infused Agency

The Infused Agency website at [infused.agency](https://infused.agency), built as a
static [Astro](https://astro.build/) site.

The original Next.js application has been retired. Astro is the only application
in this repository; the rebuild history and migration decisions live in
[`docs/astro-rebuild/`](docs/astro-rebuild/).

## Requirements

- Node.js 22 (see `netlify.toml`)
- Yarn 1.22 (`yarn --version`)

## Commands

Run these from the repository root.

| Command | What it does |
| --- | --- |
| `yarn dev` | Start the Astro dev server (`astro dev --root astro`) |
| `yarn build` | Production static build into `astro/dist` |
| `yarn preview` | Preview the production build locally |
| `yarn check:astro` | Astro type and content checks (`check` is reserved by Yarn 1) |
| `yarn validate:astro` | Validate the built HTML, links, schema, sitemap and redirects |
| `yarn verify:astro` | `check:astro` + `build:astro` + `validate:astro` |
| `yarn deploy:check` | Report whether a launch wave is scheduled for today |

`yarn validate:astro` requires a completed build in `astro/dist`.

## Project layout

| Path | Purpose |
| --- | --- |
| `astro/src/pages` | Astro routes |
| `astro/src/components` | Astro components |
| `astro/src/layouts` | Page layouts |
| `astro/src/templates` | Shared page templates |
| `astro/src/lib` | Astro data adapters and schema helpers |
| `astro/src/data/legacy` | JSON snapshots of content inherited from the retired Next.js site |
| `astro/public` | Static assets copied to the build root (`img/`, `_redirects`, `robots.txt`) |
| `data` | Service, site-fact and vertical-SEO content data |
| `posts` | Markdown blog posts |
| `src/lib` | CommonJS data/computation helpers used by the Astro build |
| `src/content/canada-niche` | Canada niche page content data |
| `src/generated/services-nav.json` | Generated navigation snapshot consumed by Astro |

Content that used to live in React page modules is stored as JSON under
`astro/src/data/legacy/`. Edit those JSON files directly; the React page tree
no longer exists.

## Deployment

The site is deployed as static files on Netlify. `netlify.toml` sets the build
command (`yarn build`) and publish directory (`astro/dist`). Redirects are
generated from `astro/public/_redirects`, and the sitemap is generated by
`astro/src/pages/sitemap.xml.ts` at build time.
